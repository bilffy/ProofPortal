## Completed changes

- Added a root `.claudeignore` excluding `vendor/`, `node_modules/`, `storage/`, build output, lock files, `.env*`, logs, IDE/OS files, test artifacts, `public/proofing-assets/` and minified assets.
- Noted that Claude Code does not read `.claudeignore` natively, so permission deny rules in `.claude/settings.json` are the supported way to block paths.
- Created `docs/FEATURE_NOTES.md` as the running log of completed changes; `CLAUDE.md` left unchanged because no architecture or UI convention changed.
- Idle timeout: `EnforceIdleTimeout` (web group, `bootstrap/app.php`) stores `last_real_activity` in the session on every non-`/api/ping` request and logs out when older than `session.lifetime`; `/api/ping` also reports `is_alive=false` then. Needed because redis/file drivers (and any request) refresh the driver expiry, so an open tab kept logins alive overnight. Not yet checked on the server.
- `/api/ping` no longer probes the session store by hand (the Redis key it built, `<app>_session:<id>` on connection `default`, never matched Laravel's real key `<redis prefix><cache prefix><id>`, so it could report live sessions as dead and force a logout ~6 min after load). `is_alive` = authenticated and not idle-expired. Not yet checked on the server.
- Slow `photography.request-download` (3.5 s on prod, measured with phase logging): the cost was the image ownership check in `PhotographyController::requestDownloadDetails()` (grouped sub-select run twice over `images`, which had no index on `keyvalue`). Now one primary-image-id lookup plus one `images`/`jobs` query, compared in PHP (same 403 rules), and migration `2026_11_20_140000_add_keyvalue_index_to_images_table` adds `images.keyvalue` and `images.ts_job_id` indexes (skipped if present). Timing logs removed after confirming on prod.
